This project is a sleek personal portfolio built using **React**, **Tailwind CSS**, and deployed on **Render**.

## Key Features

- Responsive layout
- Project routing with dynamic markdown rendering
- Hosted with free CI/CD pipeline

## How I Built It

1. Initialized the project using Vite and Tailwind CSS.
2. Designed the layout and reusable components.
3. Added JSON-based routing for scalability.
4. Deployed the finished app to Render.
